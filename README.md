# Blockchain Student Voting System

A secure, transparent, and immutable voting system for student elections using blockchain technology.

## Features

- **Data Integrity**: Cryptographic hash links prevent vote tampering
- **Vote Security**: RSA encryption for vote confidentiality
- **Transparency**: Anyone can verify vote counts without seeing individual votes
- **Consensus**: Proof of Authority for fast, efficient validation

## System Architecture

The system consists of five layers:
1. User Interface Layer (student portal & admin dashboard)
2. Blockchain Network Layer (P2P nodes)
3. Smart Contract Layer (voting rules enforcement)
4. Cryptographic Security Layer (encryption & signatures)
5. Storage Layer (blockchain & off-chain data)
